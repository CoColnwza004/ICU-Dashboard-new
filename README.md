# ICU Smart Center · โรงพยาบาลปากเกร็ด

ศูนย์ข้อมูลหอผู้ป่วยวิกฤต (ICU) ดีไซน์มินิมอลแบบ Apple — หน้าแรกแบบการ์ดเมนู, ผังเตียง, 14 ตัวชี้วัดรายวัน, ข่าวสาร,
Quality KPI, ตารางเวร, ผังบริหารงาน, คู่มือ/SOP, แนวทางการรักษา, เอกสารดาวน์โหลด, Google Forms
และ **เชื่อมกับ Google Sheet แบบเรียลไทม์ทั้งสองทาง**

- **ทุกคนเปิดดูได้** (อ่านอย่างเดียว) · **เจ้าหน้าที่ ICU ใส่รหัส** ที่เมนู “เจ้าหน้าที่ ICU” เพื่อแก้ไข/กรอกข้อมูล ประกาศข่าว และแนบไฟล์
- ทำอะไรสำเร็จจะมีป๊อปอัป ✓ กลางจอ · ผิดพลาดจะมี ✗ กลางจอ พร้อมสาเหตุ
- ดีไซน์แบบเว็บไซต์ Apple ทุกหน้า: หน้าแรกพื้นดำ · หน้าอื่นมีโหมดสว่าง/มืด (ปุ่ม ☀︎/☾ บนแถบเมนู: ตามเครื่อง → สว่าง → มืด) · พื้นหลังมีแสงนุ่ม ๆ แบบมินิมอล การ์ดลอยเบา ๆ หัวข้อไล่เฉดสีเงิน

- แก้ไขข้อมูลใน Google Sheet → หน้าเว็บอัปเดตเองภายในไม่กี่วินาที (ทุกเครื่องที่เปิดอยู่)
- แก้ไขบนเว็บ (รับ/จำหน่ายผู้ป่วย, แก้อุปกรณ์, แก้ตัวชี้วัด) → เขียนกลับลงชีตทันที
- จำหน่ายผู้ป่วย: ปรับวันเวลาที่จำหน่ายย้อนหลังได้ · Refer กรอกโรงพยาบาลปลายทาง ตึก/หอผู้ป่วย/แผนก ข้อมูลอื่น ๆ และโน้ตเพิ่มเติม (ย้ายวอร์ดกรอกตึกปลายทางได้) · ระบบจำชื่อโรงพยาบาล/ตึกที่เคยกรอกไว้แนะนำครั้งต่อไป
- ลืมกดรับผู้ป่วย: กดรับที่ผังเตียงแล้วใส่ “วันเวลาที่รับเข้า” ย้อนหลัง → ยอดรับใหม่นับเข้าวันที่รับจริง และเลือกเพิ่มยอดผู้ป่วยในวอร์ด/อุปกรณ์ของวันที่ผ่านมาได้ · ถ้าผู้ป่วยออกไปแล้ว ใช้ปุ่ม “เพิ่มเคสย้อนหลัง” ในทะเบียนหน้ารายเดือน
- ลบเคสที่บันทึกผิด/ซ้ำ: แตะแถวไหนของเคสก็ได้ในทะเบียน (หรือ ✎) › “ลบเคส” · ผู้ป่วยที่ยังอยู่ในเตียง: ลบได้จากผังเตียงด้วย (ปุ่ม “ลบเคส” เตียงกลับเป็นว่าง) → ลบทุกแถวของเคสในแท็บ Log และหักยอดรับใหม่ / Refer / เสียชีวิต (และผู้ป่วยในวอร์ด/อุปกรณ์ที่เคยนับย้อนหลัง) คืน
- แก้เคสที่จำหน่ายไปแล้วย้อนหลัง: หน้า แดชบอร์ด › รายเดือน › ทะเบียน กดไอคอน ✎ ท้ายแถวจำหน่าย (เฉพาะเจ้าหน้าที่) → แก้วันเวลารับเข้า / จำหน่าย / หมายเหตุ · ระบบแก้ทุกแถวของเคสในแท็บ Log และย้ายยอดรับใหม่ / Refer / เสียชีวิตไปวันที่ถูกต้อง
- ทุกเตียง / ทุกวัน / ทุกรายการทะเบียน มีลิงก์ “เปิดในชีต” ที่พาไปยังแถวนั้นโดยตรง
- ข้อมูลไม่ระบุตัวตนผู้ป่วย (ไม่มีชื่อ / HN)
- รองรับมือถือ แท็บเล็ต เดสก์ท็อป และโหมดมืด · พิมพ์หรือบันทึกเป็น PDF ได้ · ดาวน์โหลด CSV รายเดือน

### สูตรสถิติการใช้เตียง

| ตัวชี้วัด | สูตร |
| --- | --- |
| ADC (Average Daily Census) | วันนอนรวม ÷ จำนวนวัน |
| ALOS (Average Length of Stay) | วันนอนรวม ÷ จำนวนผู้ป่วยจำหน่าย |
| BOR (Bed Occupancy Rate) | วันนอนรวม × 100 ÷ (จำนวนเตียง × จำนวนวัน) |
| BTR (Bed Turnover Rate) | จำนวนผู้ป่วยจำหน่าย ÷ จำนวนเตียง |
| TOI (Turnover Interval) | (จำนวนเตียง × จำนวนวัน − วันนอนรวม) ÷ จำนวนผู้ป่วยจำหน่าย |

ค่าจากระบบ: วันนอนรวม = ผลรวม “ผู้ป่วยในวอร์ด” ของแท็บ Daily ในเดือนนั้น · ผู้ป่วยจำหน่าย = Refer/ย้ายวอร์ด + เสียชีวิต (Daily) + จำหน่ายกลับบ้าน (Log) ·
จำนวนวัน = ทั้งเดือน (เดือนปัจจุบันนับถึงวันนี้)

## ตั้งค่าการเชื่อมต่อ Google Sheet (ครั้งเดียว)

1. สร้าง Google Sheet ใหม่ที่ <https://sheets.new>
2. เมนู **ส่วนขยาย › Apps Script** → ลบโค้ดเดิม → วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
   (หรือกด “คัดลอกโค้ด Apps Script” ในหน้าเว็บ ⚙︎) → บันทึก
3. **Deploy › New deployment** → ชนิด **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วอนุญาตสิทธิ์
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิดหน้าเว็บ → ปุ่ม ⚙︎ มุมขวาบน → วางลิงก์ → **เชื่อมต่อ**

**เว็บนี้เชื่อมกับชีตหลักให้อัตโนมัติแล้ว** (ลิงก์อยู่ใน `src/config.ts`) เปิดจากเครื่องไหนก็เห็นข้อมูลจากชีตทันที ไม่ต้องวางลิงก์
ถ้าจะเปลี่ยนไปใช้ชีตอื่น แก้ `src/config.ts` หรือตั้ง environment variable `VITE_SHEETS_API_URL` ตอน deploy (มีผลก่อน)

### รหัสเจ้าหน้าที่ (ต้องตั้งก่อนแก้ไขข้อมูลบนเว็บ)

1. หลังวางโค้ดเวอร์ชันใหม่: ในหน้า Apps Script เลือกฟังก์ชัน **authorize** แล้วกด ▶ Run (อนุญาต Google Drive) แล้ว Deploy เวอร์ชันใหม่
2. เปิด Google Sheet (รีโหลด 1 ครั้ง) → เมนู **ICU Smart Center › ตั้ง / เปลี่ยนรหัสเจ้าหน้าที่** → ใส่รหัสอย่างน้อย 6 ตัว
3. บนเว็บ: เมนู **เจ้าหน้าที่ ICU** (ไอคอนแม่กุญแจ) → ใส่รหัส
4. (แนะนำ) เมนู **ICU Smart Center › เปิดบันทึกสถานะเตียงทุกชั่วโมง (รายงานเวรย้อนหลัง)** — กดครั้งเดียว สคริปต์จะบันทึกสถานะเตียงลงแท็บ `ShiftReports` ทุกชั่วโมง ทำให้รายงานเวรย้อนหลังตรงกับสถานะจริง

- สคริปต์เก็บเฉพาะค่า hash ของรหัส (Script Properties) ไม่มีรหัสในโค้ดหรือในชีต
- การเขียนข้อมูลทุกครั้งตรวจรหัสที่สคริปต์ · ใส่ผิด 10 ครั้งล็อก 10 นาที (ปลดล็อกได้ที่เมนูในชีต)
- ผู้เข้าชมทั่วไปอ่านได้อย่างเดียว และไม่เห็นลิงก์ Google Sheet
- **แนะนำ:** ตั้งการแชร์ Google Sheet เป็น “จำกัด” (เฉพาะคนที่เพิ่มไว้) — เว็บยังทำงานได้ตามปกติ เพราะสคริปต์ทำงานในนามเจ้าของชีต

> **API_TOKEN (ไม่บังคับ):** ตั้งในบรรทัดบนสุดของ `Code.gs` แล้วใส่รหัสเดียวกันในหน้าเชื่อมต่อ (หรือ `VITE_SHEETS_API_TOKEN`)
>
> **แก้โค้ดสคริปต์ภายหลัง:** Deploy › Manage deployments › ✏︎ Edit › Version: New version (ลิงก์เดิมใช้ต่อได้)

### ทำงานอย่างไร

```
Google Sheet ──(Apps Script Web app: doGet / doPost)──▶ หน้าเว็บ
     ▲                                                     │
     └──────────── POST เมื่อแก้ไขบนเว็บ ◀───────────────────┘
```

- หน้าเว็บดึงข้อมูลทุก 5 วินาทีขณะเปิดหน้าอยู่ (หยุดเมื่อสลับไปแท็บอื่น และดึงทันทีเมื่อกลับมา) ปรับได้ด้วย `VITE_POLL_MS`
- การแก้ไขบนเว็บแสดงผลทันที (optimistic) แล้วเขียนลงชีตตามหลัง ระหว่างบันทึกจะไม่ดึงข้อมูลเก่ามาทับ
- ถ้าเน็ตหลุด หน้าเว็บยังแสดงข้อมูลล่าสุดที่เก็บไว้ในเครื่อง
- ยังไม่เชื่อมต่อชีต? ใช้งานแบบออฟไลน์ได้ (ข้อมูลเก็บในเบราว์เซอร์) และเมื่อเชื่อมต่อครั้งแรกจะมีปุ่ม “ส่งขึ้นชีต” เพื่อย้ายข้อมูลเดิม
