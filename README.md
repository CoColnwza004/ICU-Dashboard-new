# ICU Dashboard · โรงพยาบาลปากเกร็ด

แดชบอร์ดหอผู้ป่วยวิกฤต (ICU) ดีไซน์มินิมอลแบบ Apple — ผังเตียง, 12 ตัวชี้วัดรายวัน, รายงานประจำเดือน
และ **เชื่อมกับ Google Sheet แบบเรียลไทม์ทั้งสองทาง**

- แก้ไขข้อมูลใน Google Sheet → หน้าเว็บอัปเดตเองภายในไม่กี่วินาที (ทุกเครื่องที่เปิดอยู่)
- แก้ไขบนเว็บ (รับ/จำหน่ายผู้ป่วย, แก้อุปกรณ์, แก้ตัวชี้วัด) → เขียนกลับลงชีตทันที
- ทุกเตียง / ทุกวัน / ทุกรายการทะเบียน มีลิงก์ “เปิดในชีต” ที่พาไปยังแถวนั้นโดยตรง
- ข้อมูลไม่ระบุตัวตนผู้ป่วย (ไม่มีชื่อ / HN)
- รองรับมือถือ แท็บเล็ต เดสก์ท็อป และโหมดมืด · พิมพ์หรือบันทึกเป็น PDF ได้ · ดาวน์โหลด CSV รายเดือน

## หน้าเว็บ

| แท็บ | รายละเอียด |
| --- | --- |
| ภาพรวม | ผู้ป่วยขณะนี้ / อัตราครองเตียง / Ventilator / Critical, ผังเตียง ICU-01…04, สรุป 12 ตัวชี้วัดวันนี้, กราฟ 14 วัน |
| 12 ตัวชี้วัด | ดูย้อนหลังรายวัน แก้ไขด้วยปุ่ม +/− หรือ “เติมจากผังเตียง”, กราฟแนวโน้ม 14/30/90 วัน, ตารางบันทึกรายวัน |
| สถิติเตียง | กรอก/คำนวณ ADC, ALOS, BOR%, BTR, TOI รายเดือน (เติมค่าจากระบบให้อัตโนมัติ แก้เองได้) แล้วบันทึกลงแท็บ `Stats` · พิมพ์เป็น PDF |
| รายเดือน | รับใหม่, Refer/ย้าย, เสียชีวิต, ADC/ALOS/BOR/BTR/TOI, Ventilator utilization, กราฟรายวัน, ทะเบียนเข้า–ออก · PDF/CSV มีค่าสถิติทั้งหมด |

### สูตรสถิติการใช้เตียง

| ตัวชี้วัด | สูตร |
| --- | --- |
| ADC (Average Daily Census) | วันนอนรวม ÷ จำนวนวัน |
| ALOS (Average Length of Stay) | วันนอนรวม ÷ จำนวนผู้ป่วยจำหน่าย |
| BOR (Bed Occupancy Rate) | วันนอนรวม × 100 ÷ (จำนวนเตียง × จำนวนวัน) |
| BTR (Bed Turnover Rate) | จำนวนผู้ป่วยจำหน่าย ÷ จำนวนเตียง |
| TOI (Turnover Interval) | (จำนวนเตียง × จำนวนวัน − วันนอนรวม) ÷ จำนวนผู้ป่วยจำหน่าย |

ค่าจากระบบ: วันนอนรวม = ผลรวม “ผู้ป่วยในวอร์ด” ของแท็บ Daily ในเดือนนั้น · ผู้ป่วยจำหน่าย = Refer/ย้ายวอร์ด + เสียชีวิต (Daily) + จำหน่ายกลับบ้าน (Log) ·
จำนวนวัน = ทั้งเดือน (เดือนปัจจุบันนับถึงวันนี้)

## โครงสร้าง Google Sheet

สคริปต์จะสร้าง 4 แท็บให้อัตโนมัติ (แก้ไขในชีตได้ตามปกติ แต่ **อย่าสลับลำดับคอลัมน์**)

| แท็บ | 1 แถว = | คอลัมน์ |
| --- | --- | --- |
| `Beds` | 1 เตียง | เตียง, สถานะ (ว่าง/มีผู้ป่วย/ทำความสะอาด), รหัสเคส, ระดับความรุนแรง, ช่วงอายุ, เพศ, ☑ Ventilator, ☑ C-Line, ☑ Foley, ☑ MDR, ☑ IV/HL, ☑ PI_Home, ☑ HAP_Bundle, ☑ Braden < 12, วันที่รับเข้า, เป้าหมาย/หมายเหตุ, อัปเดตล่าสุด |
| `Daily` | 1 วัน | วันที่, รับใหม่, ผู้ป่วยในวอร์ด, Refer, เสียชีวิต, Ventilator, C-Line, Foley, MDR, IV/HL, PI_Home, HAP_Bundle, Braden < 12, หมายเหตุ |
| `Log` | 1 เหตุการณ์ | เวลา, เหตุการณ์, เตียง, รหัสเคส, ระดับความรุนแรง, วันที่รับเข้า, หมายเหตุ |
| `Stats` | 1 เดือน | เดือน (yyyy-mm), จำนวนเตียง, จำนวนวัน, วันนอนรวม, จำนวนจำหน่าย, **ADC, ALOS, BOR %, BTR, TOI (สูตรในชีต คำนวณอัตโนมัติ)**, หมายเหตุ |

เริ่มต้น 8 เตียง (ICU-01…08) · ต้องการเพิ่มเตียง? เพิ่มแถว `ICU-09` ในแท็บ `Beds` ได้เลย
ช่วงอายุ: < 1 ปี (ทารก), 1–5, 6–12, 13–17, 18–39, 40–59, 60–69, 70–79, ≥ 80 ปี

เมื่อรับ/จำหน่ายผู้ป่วยจากหน้าเว็บ ระบบจะ: อัปเดตแถวเตียง, เพิ่มรายการในแท็บ `Log`, และอัปเดตแถวของวันนี้ในแท็บ `Daily`
(รับใหม่ +1 / Refer +1 / เสียชีวิต +1 และนับ “ผู้ป่วยในวอร์ด” กับจำนวนอุปกรณ์ใหม่จากผังเตียง)

## ตั้งค่าการเชื่อมต่อ Google Sheet (ครั้งเดียว)

1. สร้าง Google Sheet ใหม่ที่ <https://sheets.new>
2. เมนู **ส่วนขยาย › Apps Script** → ลบโค้ดเดิม → วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
   (หรือกด “คัดลอกโค้ด Apps Script” ในหน้าเว็บ ⚙︎) → บันทึก
3. **Deploy › New deployment** → ชนิด **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วอนุญาตสิทธิ์
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิดหน้าเว็บ → ปุ่ม ⚙︎ มุมขวาบน → วางลิงก์ → **เชื่อมต่อ**

**เว็บนี้เชื่อมกับชีตหลักให้อัตโนมัติแล้ว** (ลิงก์อยู่ใน `src/config.ts`) เปิดจากเครื่องไหนก็เห็นข้อมูลจากชีตทันที ไม่ต้องวางลิงก์
ถ้าจะเปลี่ยนไปใช้ชีตอื่น แก้ `src/config.ts` หรือตั้ง environment variable `VITE_SHEETS_API_URL` ตอน deploy (มีผลก่อน)

> **ความปลอดภัย:** ใครมีลิงก์ `/exec` จะอ่าน/เขียนข้อมูลได้ ถ้าต้องการจำกัด ให้ตั้ง `API_TOKEN` ในบรรทัดบนสุดของ `Code.gs`
> แล้วใส่รหัสเดียวกันในหน้าเชื่อมต่อ (หรือ `VITE_SHEETS_API_TOKEN`)
>
> **แก้โค้ดสคริปต์ภายหลัง:** Deploy › Manage deployments › ✏︎ Edit › Version: New version (ลิงก์เดิมใช้ต่อได้)

### ทำงานอย่างไร

```
Google Sheet ──(Apps Script Web app: doGet / doPost)──▶ หน้าเว็บ
     ▲                                                     │
     └──────────── POST เมื่อแก้ไขบนเว็บ ◀───────────────────┘
```

- หน้าเว็บดึงข้อมูลทุก 5 วินาทีขณะเปิดหน้าอยู่ (หยุดเมื่อสลับไปแท็บอื่น และดึงทันทีเมื่อกลับมา) ปรับได้ด้วย `VITE_POLL_MS`
- การแก้ไขบนเว็บแสดงผลทันที (optimistic) แล้วเขียนลงชีตตามหลัง ระหว่างบันทึกจะไม่ดึงข้อมูลเก่ามาทับ
- ถ้าเน็ตหลุด หน้าเว็บยังแสดงข้อมูลล่าสุดที่เก็บไว้ในเครื่อง
- ยังไม่เชื่อมต่อชีต? ใช้งานแบบออฟไลน์ได้ (ข้อมูลเก็บในเบราว์เซอร์) และเมื่อเชื่อมต่อครั้งแรกจะมีปุ่ม “ส่งขึ้นชีต” เพื่อย้ายข้อมูลเดิม

## พัฒนา / Deploy

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # ตรวจ type + build ไปที่ dist/
```

**Vercel:** Import repo นี้ → Framework: Vite (ตรวจจับอัตโนมัติ) → เพิ่ม Environment Variable `VITE_SHEETS_API_URL` (ถ้าต้องการ) → Deploy

เทคโนโลยี: React 19, Vite, Tailwind CSS 4, Recharts, Google Apps Script
